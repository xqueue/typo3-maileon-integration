=========================
TYPO3 Maileon Integration
=========================

:Extension key:
   typo3_maileon_integration

:Package name:
   xqueue/typo3-maileon-integration

:License:
   GPL-3.0-or-later

This extension integrates TYPO3's Form Framework with `Maileon
<https://www.maileon.com/>`__, a powerful email marketing platform. It enables
automatic contact synchronization from frontend forms, including support for
custom fields, DOI processes, and subscription/unsubscription workflows.
